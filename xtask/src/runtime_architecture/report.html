    Column key for this page

      Exclusive namespace code lines

      Physical lines carrying Rust tokens, excluding blank/comment-only/doc-comment and test-only item lines. Attribute and brace lines count; multiline literals count by physical span. Inline modules own their own lines. Conditional production branches are a union. Macro definitions count where written, not per expansion. Color is logarithmic; tile area is constant. LOC is size, not complexity or runtime cost.

      Explicit analysis limits

      Unresolved/generic targets are not guessed.
